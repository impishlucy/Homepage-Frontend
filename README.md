It showcases projects, introduces the person behind them, and connects to a backend-powered personal website.

## Features

- Responsive portfolio layout
- Dynamic content from API
- Project showcase
- About and contact pages
- Dark mode ready design
- Dashboard ready structure
- Bun based workflow

## Setup

Install dependencies and start the dev server:

    bun install
    bun dev

Open:

    http://localhost:3000

## Production

Build and run:

    bun run build
    bun start

## API

The frontend expects the backend on the matching API subdomain:

    https://api.your-domain.tld

Example:

    https://example.com -> https://api.example.com
